4. PIPELINE ORCHESTRATION STAGES (12 STAGES)
--------------------------------------------------------------------------------
1. Git Checkout     : checkout scm (Jenkins Git integration plugin)
2. Compile          : mvn compile (Validates Java 17 bytecode compilation)
3. Test             : mvn test (JUnit 5 + Surefire plugin, creates JaCoCo coverage logs)
4. Trivy FS Scan    : trivy fs --output trivy-fs-report.html (Filesystem dependency CVE check)
5. SonarQube Scan   : sonar-scanner.bat (Pushes static telemetry metrics to server)
6. Quality Gate     : waitForQualityGate (Wait for SonarQube webhook callback status)
7. Build Package    : mvn package -DskipTests=true (Creates database_service_project-0.0.5.jar)
8. Publish to Nexus : nexusArtifactUploader (Archives JAR with version 0.0.5 in releases repo)
9. Docker Build     : docker build -t manish26m/boardgame:latest (Multi-stage compilation)
10. Trivy Image Scan: trivy image --output trivy-image-report.html (Container layer check)
11. Docker Push     : docker push manish26m/boardgame:latest (Uploads image to DockerHub)
12. Deploy          : Stops/removes old container, runs new container binding host port 8085

7. COMMON RECOVERY & MANAGEMENT COMMANDS
--------------------------------------------------------------------------------
* Run Spring Boot App locally (dev port 8082):
  .\mvnw.cmd spring-boot:run -Dspring-boot.run.jvmArguments=-Dserver.port=8082

* Package JAR manually (bypassing tests):
  .\mvnw.cmd clean package -DskipTests=true

* Clean dangling local Docker images:
  docker image prune -f

* View live app container logs:
  docker logs boardgame

* Force stop and delete app container:
  docker stop boardgame && docker rm boardgame
